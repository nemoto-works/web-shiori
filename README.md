# WEB栞

Webページ上の位置に付箋を残し、同じページを開いたときに再表示するChrome拡張です。データはChromeのローカルストレージに保存され、外部サーバーへ送信しません。

## 主な機能

- ページURLと表示位置を付箋に保存
- 再訪問時の付箋表示
- 付箋の移動・編集・完了
- 選択テキスト付近への配置
- `JJ` または `Alt+Shift+J` によるクイック入力
- ポップアップから未完了・完了済み付箋を確認

## インストール

1. GitHub Actionsの最新成功ビルドから `web-shiori` artifactをダウンロードして展開します。
2. Chromeで `chrome://extensions` を開きます。
3. 「デベロッパー モード」を有効にします。
4. 「パッケージ化されていない拡張機能を読み込む」から展開したフォルダを選びます。

## 開発と確認

```sh
cd extension
npm test
npm run package
```

配布用ZIPは `artifacts/web-shiori-extension.zip` に生成されます。

## 既知の制約

- Chrome内部ページなど、拡張機能のコンテンツスクリプトを実行できないページでは利用できません。
- ページ構造が大きく変わると、選択テキストに紐づけた位置がずれる場合があります。
- 保存データは端末内のみです。端末間同期・エクスポート・バックアップは未対応です。
- Chromeウェブストアでは未配布のため、現時点では手動インストールが必要です。
